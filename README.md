# Wanderly — Travel Website

A responsive travel landing page built with React, Vite, Tailwind CSS v4, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Features

- Responsive desktop/mobile navigation with scroll-to-section links
- Animated hero, cards and hover interactions
- Destination search form with date and traveler controls
- Destination category filters
- Save/unsave destination hearts
- “Watch our story” modal
- Travel guide, experience, about and contact sections

## Notes

Destination photography is loaded from Unsplash, and Google Fonts are loaded remotely. Replace these URLs with your own optimized/local assets before production if desired. The search form is front-end demo behavior; it does not connect to a booking or travel inventory API.
